## ⚠️ Please Read ⚠️
To make changes or cancel a booking, **you must use the same device you originally booked with**. If you need assistance, please contact an Olson lab member.

This is an honor-based system — please `**do not cancel**` other people's bookings without checking with them first.
If misuse becomes an issue, access restrictions may need to be introduced 🥺

## Flow Cytometer Booking System Features
- 📅 Weekly calendar view with 30-minute time slots
- 📆 Book up to 1 month in advance
- 🔒 Required fields: Name and PI/Lab name
- 🛡️ Admin panel (password-protected) to manage bookings and block out maintenance windows
- 🖥️ Device-based booking protection — only the original device can modify or cancel a booking
